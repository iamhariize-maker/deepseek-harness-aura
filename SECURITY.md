# Security

Aura runs inside a local DeepSeek Harness web session. Workflow requests can trigger provider usage and, through Harness permissions, agent tools. Review the selected models, task and access mode before sending a workflow request.

Never include API keys, private session logs, local profile settings or exported recipes containing private notes in public issues or pull requests. To report a vulnerability, use this repository's GitHub **Report a vulnerability** option under Security if available; otherwise open an issue containing only a minimal, non-sensitive reproduction and ask the maintainer for a private channel.

Theme packs are bundled static color tokens. Aura does not execute code from linked GitHub theme projects. Its automatic model ranking uses catalogue names and does not verify provider quota, price or retention terms.
