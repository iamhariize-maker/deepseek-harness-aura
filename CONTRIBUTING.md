# Contributing

Bug reports, compatibility reports and focused pull requests are welcome. Please include your DeepSeek Harness version or commit, Node.js version, operating system, the steps to reproduce, and the observed and expected result. Redact API keys, private conversations and local account details before posting.

For code changes, run `npm test` with Node.js 22 or newer. Keep the web plugin's host entry point and client bundle compatible with the current Harness loader, and update documentation when behavior changes. Theme changes must preserve upstream attribution in `docs/THEME_SOURCES.md` and the relevant license files.

Security issues should follow [SECURITY.md](SECURITY.md) rather than a public issue.
